# שיעורי בית 3: המפתח שחוזר על עצמו

## מפגש 3: צופן ויז'נר, שיטת קסיסקי ו-Crib Dragging

בתיקייה שלך (`students/studentXX/hw3/hw3.txt`) יש טקסט באנגלית באורך של כ-1,800 אותיות, מוצפן בצופן ויז'נר עם מפתח אישי באורך 5 עד 9. הטקסט מכיל רק אותיות גדולות, בלי רווחים.

**חדש בתרגיל הזה:** הקוד נבדק אוטומטית בעזרת Unit Tests, גם אצלכם במחשב וגם ב-GitHub Actions. ההסבר המלא נמצא ב-[docs/TESTING.md](../../docs/TESTING.md).

### איך מתחילים

1. העתיקו את [solution_template.py](solution_template.py) לתיקייה שלכם בשם `solution.py`.
2. התקינו את התלויות: `pip install -r requirements.txt`
3. מלאו את הפונקציות והריצו את הבדיקות: `pytest tests/hw3 --student studentXX`

### חלק א: קוד (40% מהציון, נבדק אוטומטית)

ממשו ב-`solution.py` את הפונקציות הבאות. אסור לשנות את השמות או את הפרמטרים.

| פונקציה | מה היא עושה |
|---|---|
| `encrypt(plaintext, key)` | הצפנה בצופן ויז'נר |
| `decrypt(ciphertext, key)` | פענוח |
| `find_repeats(ciphertext, length)` | כל הרצפים באורך נתון שמופיעים לפחות פעמיים, עם המיקומים שלהם |
| `guess_key_length(ciphertext)` | אורך המפתח הסביר ביותר |
| `recover_key(ciphertext, key_length)` | המפתח, בהינתן האורך שלו |
| `break_cipher(ciphertext)` | התקפה מלאה: מחזירה את המפתח ואת ההודעה |

הבדיקות מסודרות מהקל לקשה. האחרונות מריצות את `break_cipher` על הטקסט האישי שלכם וגם על טקסט חדש עם מפתח אקראי, כך שתשובה שנכתבה ביד בתוך הקוד לא תעבור.

**שתי מלכודות שכדאי להכיר מראש:**

- אם אורך המפתח הוא 5, גם 10 מחלק את כל המרחקים. הפונקציה צריכה להחזיר את האורך הקצר ביותר שמסביר את הטקסט.
- הכלל "האות הנפוצה בעמודה היא E" עבד בשיעור, אבל לא תמיד עובד. חשבו איך להשוות עמודה שלמה לטבלת התדירויות של אנגלית. הפונקציה `english_score` מתרגיל 1 היא נקודת התחלה טובה.

### חלק ב: ניסוי

הצפינו את ההודעה שפענחתם במפתחות אקראיים באורך 5, 20, 100, ובאורך ההודעה כולה. לכל אורך מדדו שני דברים: כמה רצפים חוזרים באורך 3 יש בטקסט המוצפן, והאם `break_cipher` שלכם מצליח. צרפו גרף בקובץ `.png`.

### חלק ג: שאלות "למה" (60% מהציון)

ענו בקובץ `answers.md` בתיקייה שלכם.

1. למה רצפים חוזרים בטקסט המוצפן מגלים את אורך המפתח? הסבירו בעזרת דוגמה מהטקסט האישי שלכם, עם מיקומים ומרחקים.
2. מה קרה בניסוי כשהמפתח התארך? באיזה אורך השובר שלכם הפסיק לעבוד, ולמה דווקא שם?
3. אליס משתמשת כמפתח במשפט ארוך מתוך ספר, באורך ההודעה. קסיסקי כבר לא עובד. הסבירו איך איב שוברת את הצופן ב-Crib Dragging, ומה בדיוק במפתח אפשר לה לדעת שהניחוש שלה נכון.
4. מהם שלושת התנאים שמפתח צריך לקיים כדי שאף אחת מההתקפות שלמדנו לא תעבוד? לכל תנאי, ציינו איזו התקפה הוא חוסם.
