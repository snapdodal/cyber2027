# שיעורי בית 1: השובר האוטומטי

## מפגש 1: צופן קיסר וצופן טרנספוזיציה

בתיקייה שלך (`students/studentXX/hw1/hw1.txt`) יש שני טקסטים מוצפנים באנגלית שנוצרו במיוחד בשבילך:

- `caesar`: מוצפן בצופן קיסר.
- `transposition`: מוצפן בצופן טרנספוזיציה של עמודות. הרווחים הם חלק מהטקסט.

### המשימות

1. כתבו פונקציה `english_score(text)` שמחזירה ציון לכמה הטקסט נראה כמו אנגלית. מותר להשתמש ברשימת מילים ובספריות של Python.
2. שברו את שני הצפנים בכוח גס, כך שהתוכנית בוחרת בעצמה את המפתח הנכון, בלי שתקראו את הפלט. הגישו את המפתחות ואת הטקסטים הגלויים.
3. **ניסוי:** הצפינו בקיסר טקסטים באורכים 5, 10, 20, 50 ו-100 תווים, 30 פעמים לכל אורך. מדדו באיזה אחוז מהמקרים השובר שלכם בוחר נכון, וצרפו גרף.

### שאלות "למה" (60% מהציון)

- למה השובר נכשל בטקסטים קצרים? הסבירו על סמך התוצאות שלכם.
- כמה מפתחות ניסה השובר שלכם בטרנספוזיציה? כתבו נוסחה למספר המפתחות כתלות באורך ההודעה.
- הציעו שינוי אחד בצופן שיהפוך את השובר שלכם לחסר תועלת, והסבירו למה.

### הגשה

קוד (קובץ `.py` או מחברת), גרף, ותשובות כתובות, בתיקייה `students/studentXX/hw1/`. מחוון: קוד 40%, הסבר 60%.

**שימו לב:** הטקסטים שונים לכל תלמיד. פתרון שמתאים לתלמיד אחר לא יתקבל.
